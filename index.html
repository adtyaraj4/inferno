About

An original project, built from scratch

INFERNO // PROTOCOL is an independent, original browser game built with Three.js and vanilla JavaScript for a college web-development recruitment task. Every character, weapon, enemy, and environment is original — inspired by the tone of 1990s corridor shooters, built with none of their assets.
